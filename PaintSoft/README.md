# PaintSoft

シンプルなお絵かき（ペイント）アプリです。ブラウザで `index.html` を開くだけで動作します。

加えて、Windows向けにデスクトップアプリ（WPF + WebView2）としても起動できます。

## 使い方

- `index.html` をブラウザで開く
- ドラッグ（またはペン）で描画
- ツール：ブラシ / 消しゴム / スポイト / バケツ / ハンド（ブラシ設定パネルまたはショートカットで切り替え）
  - **バケツ**: クリックした位置と同じ色（多少の誤差は許容）の連続した範囲を現在の色で塗りつぶします。塗りつぶし対象は選択中のレイヤーのみです
- 色・背景色はトップバーに常設（ブラシごとの設定には従属しません。ブラシ切り替えで変わりません）
- ブラシ設定パネルでは、太さ・不透明度・ぼかし・間隔の変更（下記参照）
- ブラシ設定パネル上部の「ブラシ」リストで、上記設定の組み合わせを名前を付けて複数保存・切り替え可能。リストから選ぶとその設定が下の「現在の設定」に反映されます（＋で現在の設定を新規保存、💾で選択中のブラシを上書き、－で削除。`localStorage` に保存され次回起動時も引き継がれます）。ブラシリストと「現在の設定」は別のUIとして分離されています
- 「現在の設定」のスライダー類は変更するたびに自動的に（リアルタイムに）保存され、次回起動時にそのまま復元されます。ブラシとして名前を付けて保存したい場合とは別に、常に「今使っている設定」が保たれます
  - **筆圧レンジ（太さ / 不透明度）**: 「太さ」と「不透明度」はどちらも同じ形式の共通コンポーネントです。それぞれに基本値（太さ／不透明度そのもの）と、その基本値に対する「最小」「最大」の割合（％）、「筆圧を適用」チェックボックスがあります。チェックを外すと、そのパラメータは筆圧を無視して常に最大値になります（太さの最大は基本値の100%まで）
  - **ぼかし**: ペン先の輪郭のぼかし具合です。0にすると完全な二値（アンチエイリアスなし）のくっきりした輪郭になり、値を上げるほどエアブラシのように輪郭がにじみ、中心の実体は小さくなりながら周囲に柔らかいハローが太さの見た目より外側まで広がります
- `グローバル設定` ダイアログ（トップバー）に、手ブレ補正・筆圧補正・筆圧ON/OFF・ツール切り替えの長押し確定時間・ショートカットのキー割り当てをまとめています。手ブレ補正等は特定のブラシに紐づかず、すべてのブラシ・消しゴムに共通で適用されます（ブラシプリセットには保存されません。設定は変更するたびに自動保存されます）。ショートカットのキー割り当てのみ「保存」ボタンで確定する方式です（下記参照）
- スポイトでキャンバス上の色を採取
- `クリア` で全消去
- `PNG保存` で画像を書き出し
- `プロジェクト保存` / `プロジェクトを開く` で本アプリ専用の `.psft` ファイルとして保存・再読み込み（レイヤー・フォルダ・ノード接続を完全に保持）
- `プロジェクトを閉じる` で現在のプロジェクトを破棄し、新規プロジェクト（初期状態のレイヤー1枚・デフォルト解像度）を開始します（確認ダイアログあり。元に戻す履歴も含めてクリアされるため注意してください）
- `PSD書き出し` でPhotoshop形式（.psd）としてレイヤーを維持したまま書き出し（簡易再現・下記参照）
- `キャンバス設定` でキャンバスの解像度変更・サイズ変更（下記参照）

トップバーの各種ボタン（ファイル操作、レイヤー/フォルダ追加・削除、設定ダイアログを開くボタン）は全てヘッダー内に集約されています。

## ショートカット

`グローバル設定` ダイアログ内の「ショートカット」セクションから、キー割り当てを自由に変更できます（`localStorage` に保存され、次回起動時も引き継がれます）。他のグローバル設定と違い、キー割り当ての変更は「保存」ボタンを押すまで確定しません（誤ってキーを取り違えて保存してしまうのを防ぐため）。

デフォルトのキー割り当て:

- ブラシに切り替え: `B`
- 消しゴムに切り替え: `E`
- スポイトに切り替え: `I`
- バケツに切り替え: `G`
- ハンドツールに切り替え: `Space`（押している間だけ一時的にハンドツールになり、キャンバス上をドラッグすると表示位置を移動できます。短く押してすぐ離すとハンドツールに切り替わったままになります）
- 元に戻す: `Ctrl+Z`
- やり直し: `Ctrl+Y`（`Ctrl+Shift+Z` も常に有効な固定の代替キーとして動作します）
- 表示位置を初期化: `Ctrl+0`（トップバーの `表示リセット` ボタンでも同じ操作ができます。パン・ズームを初期状態〈中央・等倍表示〉に戻します）
- ズーム: `Ctrl+Space` を押しながらキャンバス上を左右にドラッグ（右で拡大、左で縮小・このショートカットは変更できません）。ドラッグを始めた時点でパネルの中央に表示されている位置を中心にズームします（パンしていても、その時点で画面中央に見えている場所が動かないままズームされます）。表示が等倍（画面の1ピクセルがキャンバスの1ピクセル）以上に拡大されると、自動的にドット単位のくっきりした表示に切り替わります。逆に縮小表示のときは、高品質な補間で滑らかに縮小されます（ブラウザ標準のキャンバス拡大縮小に頼らず、アプリ側で都度描き直しているため、大きく縮小してもガビガビしません）

表示位置はパネルの範囲を超えて自由に移動できます（オーバーパン。移動しすぎて見失った場合は `Ctrl+0` / `表示リセット` で戻ってください）。

**ツール切り替えの長押し挙動**（全ツール共通の仕組みです）:

- キーを押した瞬間に即座にそのツールへ切り替わります（待ち時間はありません）
- 設定した時間（`グローバル設定` の「ツール切り替えの長押し確定時間」、デフォルト350ms）以内に離す → クリックと同じ「切り替えたまま」になります
- それより長く押し続けてから離す → 直前のツールに戻ります

## レイヤーフォルダ

ノードパネルの「📁＋」でフォルダノードを追加できます。フォルダの「＋」でフォルダ内に新規レイヤーを作成、各レイヤー行の「×」でフォルダから出せます。フォルダ自体も出力ノードや他のノードへ接続でき、フォルダの合成順はフォルダノードの位置で決まります（中のレイヤーは追加した順に重なります）。フォルダの「－」を押すと、中のレイヤーごと削除されるので注意してください。

フォルダの中にはサブフォルダも作成できます（フォルダの「📁＋」）。サブフォルダは行として表示され、▶/▼ボタンで開閉、中に「＋」でレイヤー、「📁＋」でさらにサブフォルダを追加できます。階層はいくつでも深くできます。外側のフォルダを削除すると、中のサブフォルダ・レイヤーもまとめて削除されます。

## キャンバスサイズ・解像度

キャンバスの実際のピクセル解像度（`キャンバス設定` で変更）と、画面上での表示サイズ（キャンバスパネル右下のハンドルをドラッグして変更）は独立しています。パネルを拡大縮小しても絵がリサンプリングされることはなく、常に元の解像度のまま縦横比を保って表示されます（パネルのリサイズハンドルは角の1つのみで、縦横比を維持したまま拡大縮小します）。

`キャンバス設定` ダイアログには2つのモードがあります:

- **解像度変更（リサイズ）**: 既存の絵を新しいピクセルサイズに合わせて拡大縮小します（画像編集ソフトの「画像解像度」に相当）
- **キャンバスサイズ変更（切り抜き/拡張）**: 絵の内容はそのまま、キャンバスの範囲だけを切り抜き・拡張します。9箇所の基準位置から、既存の絵をどこに固定するか選べます（画像編集ソフトの「カンバスサイズ」に相当）

どちらも通常の操作として元に戻す（Undo）が可能です。

## 書き出し形式について

### プロジェクト保存（.psft） — 本アプリ専用形式・完全対応

`プロジェクト保存` は、レイヤーのピクセルデータに加えてフォルダ構造・ノードの接続関係・表示状態など全ての情報をJSONとして書き出す、本アプリ専用のロスレス形式です。`プロジェクトを開く` で読み込むと、保存時点の状態を完全に復元します。作業を中断・再開したいときはこの形式を使ってください。

### PSD書き出し — 簡易再現

`PSD書き出し` は、独自実装のPSDライター（外部ライブラリ不使用・非圧縮RAWエンコード）でレイヤーをPhotoshop形式として書き出します。Photoshop / GIMP 等で個別レイヤーとして開けますが、以下は簡易化されています:

- フォルダはグループ化されず、キャンバス上と同じ重なり順で展開されます
- 不透明度・合成モードは常に「通常・100%」（本アプリ自体がレイヤーごとの不透明度/合成モードを持たないため）
- ノードグラフで出力ノードに接続されていないレイヤーは、キャンバスの合成結果と同様に書き出し対象外です

### .clip ファイルの読み込み・保存（デスクトップ版限定・非公式）

デスクトップ版のツールバーには「開く (.clip)」「保存 (.clip)」ボタンがあり、CLIP STUDIO PAINT の `.clip` ファイルをレイヤー単位で読み込み・書き出しできます。

**注意**: `.clip` はCELSYS社の非公開フォーマットで、公式仕様は公開されていません。この機能は有志によるリバースエンジニアリング情報（[clip-d](https://github.com/Inochi2D/clip-d) / [clip_to_psd](https://github.com/dobrokot/clip_to_psd)）を参考にした非公式・実験的な実装です。そのため:

- 対応するのは通常のラスターレイヤーのみです（ベクターレイヤー・テキストレイヤー・調整レイヤー・マスクは読み込めません）
- フォルダ構造は展開され、レイヤーの不透明度・合成モードは反映されません（読み込み後は不透明・通常合成として扱われます）
- CLIP STUDIO PAINTのバージョンやファイルの内容によっては読み込みに失敗する場合があります
- **「保存 (.clip)」は本アプリの読み込み機能が理解できる構造で `.clip` 形式のファイルを書き出しますが、CLIP STUDIO PAINT本体で開けることは保証されません。** 実際のCSPファイルが内部的に持つ情報（ドキュメント設定、サムネイル、カラープロファイルなど）の多くは再現されておらず、本アプリ同士での再読み込み用途を主な対象としています

## デスクトップ版（Windows）

前提:

- .NET SDK（本リポジトリは `net9.0-windows`）
- WebView2 Runtime（多くのWindowsには既に入っています。未導入の場合はインストールが必要です）

起動:

```powershell
dotnet run --project .\PaintSoft.Desktop\PaintSoft.Desktop.csproj
```

### 実行ファイル（exe）

すぐ使える実行ファイルはリポジトリ直下の **[`_exe`](../_exe/PaintSoft.Desktop.exe)** フォルダに置いています。`_exe\PaintSoft.Desktop.exe` をダブルクリックすれば起動します（.NETランタイム同梱の自己完結型ビルドのため、.NET未インストールのPCでも動作します）。

再ビルドして `_exe` フォルダを更新する場合:

```powershell
dotnet publish .\PaintSoft.Desktop\PaintSoft.Desktop.csproj -c Release -r win-x64 --self-contained true -o ..\_exe
```
